รายการปรับ SEO ทั้งเว็บไซต์ วันที่ 25 กันยายน 2569

1. ปรับ Title, Meta Description และ H1 ของหน้าหลัก หน้ารวมสินค้า หน้าบทความ และหน้าโซลูชัน
2. แยกเจตนาคำค้นหาให้ชัดเจน
   - หน้าผลิตภัณฑ์รวม: ผลิตภัณฑ์ระบบน้ำและพลังงาน
   - หน้าหมวดเครื่องกรองน้ำประปา: โรงกรองน้ำประปา / เครื่องกรองน้ำประปาชุมชน
   - หน้าสินค้า: โรงกรองน้ำประปา 12Q และโรงกรองน้ำประปา 24Q
3. เพิ่มเนื้อหาประกอบและ Internal Link ในหน้าหมวดโรงกรองน้ำประปา
4. เพิ่มคำถามที่พบบ่อยเกี่ยวกับการเลือกขนาด แหล่งน้ำ และข้อมูลสำหรับขอราคา
5. ปรับหน้าหมวดสินค้าอื่นให้รับคำค้นกว้างของแต่ละหมวด โดยไม่แย่งกับหน้าสินค้า
6. ปรับหน้าหมวดอุตสาหกรรมให้ใช้คำตามลักษณะงานจริง
7. คง noindex ให้หน้าจำลองและสินค้าที่ปิดแสดง จึงไม่เพิ่มหน้าบางเข้า Google
8. อัปเดต Open Graph, Twitter metadata และ Structured Data ให้ตรงกับข้อความใหม่
9. สร้าง CSS ใหม่จาก Tailwind โดยคงดีไซน์และ component เดิม

ผลตรวจสอบ
- HTML ทั้งหมด 81 หน้า
- อนุญาตให้จัดทำดัชนี 39 หน้า
- noindex 42 หน้า
- Sitemap 39 URL ตรงกับหน้าที่อนุญาตให้จัดทำดัชนี
- ไม่พบลิงก์ภายในเสีย
- ไม่พบ Title หรือ Meta Description ซ้ำในหน้าที่จัดทำดัชนี
- ทุกหน้ามี H1 หนึ่งรายการ
- Structured Data JSON-LD อ่านได้ทุกหน้า

หมายเหตุหลังอัปโหลด
- ส่ง sitemap.xml ใน Google Search Console อีกครั้งได้
- ขอจัดทำดัชนีหน้าหมวด /products/water-filtration/ ก่อน
- ไม่จำเป็นต้องขอจัดทำดัชนีทุกหน้าในวันเดียว Google จะตามลิงก์จาก Sitemap และ Internal Link
