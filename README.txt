หมายเหตุการ Deploy
------------------
- ให้วาง index.html, robots.txt และ sitemap.xml ที่รากของ Repository
- ตั้งค่า HostAtom/Plesk ให้ดึง branch ที่ใช้งานจริงของ Repository นี้
- หลัง Deploy ตรวจว่า Canonical, robots.txt และ sitemap.xml ใช้ https://sunnext.co.th เท่านั้น
